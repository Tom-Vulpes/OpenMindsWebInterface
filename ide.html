Run code quickly
Click Run code to save code.py to the CIRCUITPY drive. The board restarts automatically. You only need to pick the drive once per session.
while True: loops
Most board programs run forever inside while True:. Add time.sleep(0.1) inside the loop — without a delay the board can freeze or generate too much output.
Touch pad faults
Wrap pad reads in try/except — a pad with a missing resistor will throw an exception. The examples do this automatically so one bad pad doesn't stop the others.
NeoPixel brightness
The 12 LEDs are very bright. Use brightness=0.05 as a starting point. Full brightness generates significant heat and draws too much current from USB.
Reading sensors
Analogue reads (analogio.AnalogIn) return 0–65535. Divide by 65535 to get 0.0–1.0, or scale to a useful range with simple maths. Use print() to see the raw values.
i2c devices
All i2c devices share the same two wires (SDA=GP14, SCL=GP15). You can connect multiple sensors at once as long as they have different addresses. Use i2c.scan() to find what's connected.
Servo range
Set angle with my_servo.angle = 90 (0–180). Signal on GP22. If the servo buzzes at limits, adjust min_pulse and max_pulse in the Servo() constructor.
Motor driver power
The motor driver hat needs its own power supply for the motors — don't run motors from USB alone. Connect a separate battery pack to the hat's power terminals. The logic still runs from USB.
Wireless (coming soon)
The Pico W has a built-in Wi-Fi chip. Wireless examples for V2 are in development — check the Open Minds GitHub for updates.
CIRCUITPY drive
CircuitPython mounts as a USB drive. code.py runs on boot. If the board crashes, it shows a red LED. Connect via serial to see the error message, then fix and re-run.
